Student Result Card

A beginner-friendly Python program that creates a simple student result card by calculating total marks, average marks, and a grade based on marks in Python, Mathematics, and English.

About the Project

I am a freshman undergraduate learning Python. This project is part of my beginner programming practice and combines user input, arithmetic operations, conditional statements, and formatted output.

What the Program Does

Takes the student's name.

Takes marks for Python, Mathematics, and English.

Calculates the total marks.

Calculates the average marks.

Assigns a grade based on the average.

Displays the student's result card.
